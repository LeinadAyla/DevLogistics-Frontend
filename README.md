# 📦 DevLogistics - Gestão Inteligente de Estoque

> Sistema full-stack para otimização de controle de estoque e processos logísticos.

## 🚀 Arquitetura
- **Frontend:** Angular (Busca inteligente e tolerante a falhas).
- **Backend:** Python / Flask (API REST & SQLAlchemy).

## ⚙️ Execução
- **Backend:** cd backend | python -m venv venv | .\venv\Scripts\Activate | pip install -r requirements.txt | python run.py
- **Frontend:** cd frontend | npm install | ng serve
